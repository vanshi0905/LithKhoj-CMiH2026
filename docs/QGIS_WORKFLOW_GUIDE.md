# LithKhoj QGIS Integration & Raster Styling Standard Operating Procedure (SOP)

## 1. Scope & Objective
This guide outlines the standard workflow for importing, styling, and analyzing multi-sensor satellite prospectivity rasters generated by **LithKhoj** inside desktop GIS suites (QGIS 3.28+ / ArcGIS Pro).

Target Area: **Katghora Lithium & Rare Metal Block, Korba District, Chhattisgarh, India**  
Projected Coordinate Reference System (CRS): **EPSG:32644 (WGS 84 / UTM Zone 44N)**

---

## 2. Ingesting Spectral & Evidential Rasters

### Step 1: Loading Multi-Spectral GeoTIFFs
1. Launch QGIS and set project CRS to `EPSG:32644`.
2. Add the following raster deliverables from the `output/` directory:
   * `katghora_lithium_prospectivity.tif` (Unified ensemble prospectivity score, range `0.0` to `1.0`)
   * `index_cardoso_LMDR_lithium_mica.tif` (Lithium Mica Dissimilarity Ratio: Band 8 / Band 12)
   * `index_cardoso_LPI_lithium_pegmatite.tif` (Lithium Pegmatite Index: Band 2 / Band 4)

### Step 2: Pseudocolor Colormap Styling
1. Right-click `katghora_lithium_prospectivity.tif` $\rightarrow$ **Properties** $\rightarrow$ **Symbology**.
2. Set **Render type**: `Singleband pseudocolor`.
3. Set **Color ramp**: `Magma` or `Viridis` (inverted, so highest probability renders deep crimson/gold).
4. Mode: `Quantile` or `Equal Interval` with **5 classes**:
   * `< 0.20`: Non-prospective host rock (granite-gneiss baseline)
   * `0.20 – 0.50`: Background country rock
   * `0.50 – 0.70`: Weak alteration halo
   * `0.70 – 0.85`: High-probability pegmatite intrusion
   * `> 0.85`: Priority Exploration Vector (Tier-1 Drill Target)

---

## 3. Overlaying GSI Borehole Data

1. Import GSI field borehole collars from `data/drillholes_katghora.geojson`.
2. Apply categorized symbology based on assay lithium grade (`Li_ppm`):
   * `< 250 ppm`: Grey circle (background)
   * `250 – 500 ppm`: Yellow circle (anomalous)
   * `500 – 1000 ppm`: Orange diamond (sub-economic pegmatite)
   * `> 1000 ppm`: Red star (economic spodumene/lepidolite intercept)
3. Label drillholes using `Borehole_ID` with a 1mm text buffer for map clarity.

---

## 4. Quality Checks & Spatial Audit
* Verify raster dimensions match native Sentinel-2 $10\text{m} \times 10\text{m}$ resolution.
* Ensure zero NoData bleeding across cloud-masked areas.
* Export print-ready composite layout at $300\text{ DPI}$ with scale bar and north arrow.
